Privacy notice

Last updated 28 October 2026

Orbit Personal is a self-hosted personal planning app. Your private Orbit instance runs on a device controlled by its owner. This public website explains its calendar connections; it does not connect to your accounts or your private instance.

Calendar information

Orbit uses connected calendar information to calculate availability and suggest focus windows around existing commitments. It keeps busy start and end times, connection status and the calendar selections needed to perform those checks.

  • Google Calendar: Orbit requests free/busy availability for the authorized account’s primary calendar.
  • Microsoft Outlook: Orbit requests event start and end times, free/busy status and cancellation status from the personal account’s default calendar.
  • Apple iCloud: Orbit reads the calendars the owner explicitly selects. Calendar entries are processed temporarily to interpret repeating, all-day and time-zone-dependent events. Only busy intervals are retained.

Orbit does not retain event titles, event descriptions, attendee lists or attachments from these calendar checks. It does not create, edit or delete provider calendar entries.

Private storage and account access

Access and refresh tokens, OAuth application settings and iCloud app-specific passwords are stored in the private Orbit instance. The public information site receives none of these credentials. Connection credentials and cached busy intervals are excluded from Orbit’s personal planning export.

The instance uses restricted filesystem permissions for its private database and HTTPS for calendar-provider connections. The owner remains responsible for protecting the device, private network and backups. This does not claim separate encryption of the local database.

How information is used

Calendar information is used for availability-aware personal planning. It is not sold, used for advertising, or used to train AI models. Calendar event content is not supplied to Orbit’s AI model.

When using Google Calendar information, Orbit follows the Google API Services User Data Policy, including its Limited Use requirements.

Optional phone notifications contain generic reminders; calendar event details are not included. Calendar providers process the requests needed to supply availability under their own account policies.

Retention and disconnection

Each successful refresh replaces the current cached availability. An unavailable or stale calendar is not treated as free time. Expired information may remain cached until a refresh or disconnection, but is excluded from scheduling.

Disconnecting an account removes its active access and refresh tokens or iCloud password, calendar selection and cached availability from the running instance. OAuth application setup may remain for reconnecting. Separate private backups may contain earlier copies and are managed by the instance owner.

Account permissions can also be revoked in the provider’s account settings. Revoking provider access does not automatically delete private backups.

This public website

These are static information pages. They have no forms, sign-in controls, scripts, advertising or analytics added by Orbit. They do not contact the private Orbit app and cannot read your projects or calendars.

The site is hosted on GitHub Pages. GitHub may process normal request information, including visitors’ IP addresses, for hosting and security. See the GitHub General Privacy Statement.

Questions and changes

For questions about data in a private instance, contact the person who administers that instance. For Google authorization questions, the consent screen provides the application’s support contact. This notice will be updated when the calendar data-handling behavior changes.

Keep credentials in the private app. This information site never asks for a password, access token, calendar credential or payment.
